# Solarvest Bursa Monitor

Public daily log of Solarvest Holdings (Bursa: 0215) announcements and closing prices, updated automatically each weekday evening (about 7:37pm MYT).

- `index.html` is the page
- `data/` holds the data files (announcements, prices, daily checks) refreshed by the scheduled update

Prices come from market-data services (KLSE Screener, cross-checked with Investing.com), not an exchange-certified feed. Dated facts only; no causes are attributed to price moves.
